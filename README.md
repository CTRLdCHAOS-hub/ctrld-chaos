# CTRL'd Chaos

**TikTok LIVE gifts → chaos in the games you stream.**

Viewers send gifts, things happen in your game. Coins, bricks, jail cells, knock-outs, pyramid collapses. You pick which gift does what, and a scrolling overlay shows your viewers what each gift does.

## ⬇️ Download

**[Get the latest version](../../releases/latest)** and download `CTRLd-Chaos-Setup-x.x.x.exe`.

Windows 10/11 (64-bit). Windows may say *"Windows protected your PC"* because the installer isn't code-signed yet: click **More info → Run anyway**.

## 🚀 Getting started

1. Install CTRL'd Chaos and open it.
2. Pick your game in the **Library** (it finds your Steam games automatically).
3. With the game **closed**, click **🧩 Install mod** in the setup steps.
4. Click **⚡ Load starter preset** (or **＋ Add gift event**) and pick a gift for each effect.
5. Type your TikTok username, start your LIVE, press **Go LIVE**.
6. **Overlay:** open the Overlay page, then add the overlay window to TikTok LIVE Studio or OBS with **Window Capture**.

Wipes and collapses stay off until you switch on **Allow wipes & collapses** in the game's Danger zone. Your save is backed up before any of them run.

## 🔄 Updating

Download the newest installer and run it over the top. Your settings and gift events are kept. If the release notes mention a mod update, click **↻ Update mod** with the game closed.
